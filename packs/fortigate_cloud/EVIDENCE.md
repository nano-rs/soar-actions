# Fortigate Cloud API references

Cloud block/unblock definitions require access to the vendor FNDN API reference. Documented cloud environments are Global (api.fortigate.forticloud.com), US (usapi.fortigate.forticloud.com), Europe (euapi.fortigate.forticloud.com), and Japan (jpapi.fortigate.forticloud.com). API access: https://docs.fortinet.com/document/fortigate-cloud/26.1.0/administration-guide/557024/api-access .

## Unsupported operations

- `cloud_block_ip`: The official endpoint reference requires vendor portal access; public request and response definitions are unavailable. References: https://docs.fortinet.com/document/fortigate-cloud/26.1.0/administration-guide/557024/api-access, https://fndn.fortinet.net/.
- `cloud_unblock_ip`: The official endpoint reference requires vendor portal access; public request and response definitions are unavailable. References: https://docs.fortinet.com/document/fortigate-cloud/26.1.0/administration-guide/557024/api-access, https://fndn.fortinet.net/.
- `on_prem_block_ip`: Customer-managed appliance or instance hosts require an on-premises relay and are unsupported. References: https://docs.fortinet.com/document/fortigate/7.6.3/administration-guide/712168/accessing-fortinet-developer-network.
- `on_prem_unblock_ip`: Customer-managed appliance or instance hosts require an on-premises relay and are unsupported. References: https://docs.fortinet.com/document/fortigate/7.6.3/administration-guide/712168/accessing-fortinet-developer-network.
