# Sentinelone API references

Disconnect/connect are unavailable until the official endpoint request and response definitions are accessible. The Management API reference requires vendor login: https://usea1-partners.sentinelone.net/api-doc/overview .

## Unsupported operations

- `disconnect_agent`: The official endpoint reference requires vendor portal access; public request and response definitions are unavailable. References: https://usea1-partners.sentinelone.net/api-doc/overview.
- `connect_agent`: The official endpoint reference requires vendor portal access; public request and response definitions are unavailable. References: https://usea1-partners.sentinelone.net/api-doc/overview.
